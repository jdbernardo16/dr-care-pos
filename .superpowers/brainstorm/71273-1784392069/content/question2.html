Cart Header & Item Rows

Two more decisions to narrow down the design.

1. Cart Header Toolbar

Currently: Comments, Taxes, Coupons, Settings, Quick Product buttons visible above cart items. Where should these go?

A

Inline Icon Bar (compact)

Small icon-only row above cart items. No text labels, cleaner look. Expand on tap.

B

Behind "..." Menu

Move to the same ⋮ menu as Hold/Discount/Void. Cleanest cart header.

C

Move to Top Header Bar

Move to the top toolbar (next to Customers, Order Type). Frees up cart space.

2. Product Item Rows

Currently has separate Qty and Total columns with action icons. Loyverse uses simpler rows with inline quantity.

A

Loyverse-style Rows

Item name + inline qty (× 2) + line total. Tap item to adjust qty. Swipe to delete. Cleanest.

B

Compact Columns

Keep columns but reduce padding/font sizes. Name takes most space, qty and total are smaller.

C

Keep Current (restyle)

Same layout, just update colors/spacing/typography to match modern look.
