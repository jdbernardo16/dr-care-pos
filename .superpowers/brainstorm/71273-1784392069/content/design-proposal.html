What's changing:

New Design

  • Narrower left cart panel (~38% width) — like Loyverse
  • Simpler item rows — name + inline qty (×2) + total
  • Totals section — cleaner, less prominent (sub/discount/tax/total)
  • Single "Charge ₱XX" button + ⋮ menu for Hold/Disc/Void
  • Cart header buttons moved behind ⋮ menu
  • Category chips (pills) at top of product grid
  • Minimal top-bar icons (search, customers, order type)

Preserved Functionality

  • Comments, Taxes, Coupons — accessible via ⋮ menu
  • Hold — accessible via ⋮ menu
  • Discount — accessible via ⋮ menu
  • Void/Clear — accessible via ⋮ menu
  • Customer selection — top bar icon
  • Order type — shown inline in cart header
  • All existing popups and interactions remain
